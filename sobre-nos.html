SOBRE O PATRONUSNET

As pessoas por trás da extensão.

O PatronusNet é um projeto acadêmico que resultou em uma extensão de navegador para controle parental por domínio e por palavras-chave. Conheça quem desenvolveu e orientou o projeto.

NOSSA PROPOSTA

Segurança não precisa ser complicada.

O PatronusNet nasceu como um projeto acadêmico para explorar como uma extensão de navegador pode oferecer controle parental acessível, com processamento local e configuração simples.

01
◈

Controle por domínio

A extensão permite definir quais domínios podem ou não ser acessados durante a navegação.

02
🏷️

Bloqueio por palavras-chave

Além do domínio, a extensão bloqueia páginas cujo texto ou endereço contenha os termos cadastrados.

03
🔒

Processamento local

As configurações e a lógica priorizam o processamento local, mantendo os dados sob controle do usuário.

Tecnologias utilizadas.

01

Extensão

Chromium Manifest V3, service worker, scripts de conteúdo e página de opções.

02

Web

HTML5, CSS3 e JavaScript para as interfaces do popup e das configurações.

03

Armazenamento

APIs de storage do navegador para guardar políticas e preferências localmente.

04

Navegação

APIs de tabs e webNavigation para verificar os domínios acessados e aplicar as regras.
